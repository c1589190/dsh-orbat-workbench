# 原编辑器样式编制预览设计

用户要求网页与导出图片都采用原编辑器的样式，并明确说“对面是开源项目，直接抄”。本地参考 Army_Editor 快照 commit e5bd0eb288afec143dc9bf202f1aa16ee6ff07d5，版本标为 1.8.0。直接以其布局、符号几何、连线及角标实现为依据适配，记录来源及作者 BiliBili@勘茶Kchs_ 与 DeepSeek，保留其声明；仓库未见标准许可证，不声称获得再分发授权。

- 网页与导出 PNG/SVG 使用同一份服务端渲染；默认 `editor` 模式，保留 `list` 模式切换。工具不指定模式默认 `editor`。
- 适配上游 120×120 兵牌、72×70 符号、人数与装备的含下属角标、横纵各节点排版和连接线、`collapsed` 和 `stack`；不复制其独立编辑器及存储逻辑。不可损坏共享编制文档、ID、revision 或历史。
- 与上游相同方向的视觉布局优先，保留文字转义、清晰截断提示、200 节点默认限制、2400×16000 像素界限、相同 SVG/PNG 内容。若宽度超限，不能静默裁掉内容或称完整；可安全缩放或报告真实截断。可见堆叠与折叠数量语义明确。
- 图像或网页均非原站截图；跨版本字体差异不能保证像素一致。原站的拖拽、缩放和平移交互不是本次承诺，但网页可滚动查看完整图片。
- `mode` 只接受 `editor`/`list`，缓存键、URL、导出文件名区分模式。不可改变编辑器数据或造成两个模式互相污染。每项新增行为以真实渲染器测试验证，最终确认老列表模式和现有数据操作无回归。
- 不启动替代 DSH、不改用户 profile、不自动重启；当前运行实例如未加载新版后端要清楚告知，绝不把本地测试或独立生成图称为运行中 GUI 的视觉验收。
